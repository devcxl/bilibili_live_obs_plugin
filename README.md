# B站直播工具 — OBS 插件

单文件 `bili_live_obs.py`，直接在 OBS 中加载使用。

## 安装

### 1. 安装依赖

```bash
pip install requests cryptography
```

### 2. 加载

OBS → 工具 → 脚本 → + → 选择 `obs_plugin/bili_live_obs.py`

## 使用

1. **扫码登录** — 点击「扫码登录」自动打开浏览器，用 B站客户端扫码确认
2. **配置直播** — 填写标题，选择分区
3. **开播** — 点击「开始直播」
4. **配置推流码** — 复制推流地址、推流码到Obs直播配置中。
5. **停播** — 点击「停止直播」

> OBS 的停止串流不会结束 B站直播，需在面板中操作。
