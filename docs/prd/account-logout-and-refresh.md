# PRD：账号退出按钮 + OBS 启动时自动刷新账户信息

## 背景

当前 B 站直播工具的登出功能仅在多账号时显示（`btn_logout_` 位于账号切换行底部），单个账号登录后没有直观的退出入口。此外，每次打开 OBS 恢复会话时使用的是本地缓存数据，账户信息可能已过时（等级、关注数、粉丝数等），需要主动从 B站 API 刷新。

## 需求概要

两个独立功能点：

### 1. 右上角退出登录按钮

- **位置**：面板右上角，与标题 "B站直播工具 - OBS 插件" 同行，靠右对齐
- **行为**：登录态可见，点击后清除当前登录态并回到未登录界面
- **边界**：
  - 单账号也显示退出按钮
  - 多账号切换区域保留原有 `btn_logout_`（或移除重复）

### 2. OBS 启动时自动刷新账户信息

- **时机**：OBS 前端加载完成、插件 dock 初始化并恢复会话后
- **行为**：异步调用 B站 API 获取最新用户数据（等级、关注、粉丝、硬币等），更新本地缓存和 UI 显示
- **边界**：
  - 仅在有有效 session 时触发
  - 刷新失败不影响正常使用（静默降级）
  - 非阻塞 —— 不阻塞 dock 加载和 OBS 界面渲染

## 技术约束

- C++17 / Qt6 / OBS Plugin API（不可引入新依赖）
- 所有网络请求必须异步（不阻塞 UI 线程）
- `set_logged_out()` 需保持行为不变
- `refresh_current_user()` 已有 API 调用逻辑，UI 侧只需新增调用点

## 验收标准

### 退出按钮
1. 登录后，面板右上角显示一个退出按钮
2. 单账号和多账号均显示该按钮
3. 点击后：Cookie 清除、UI 回到未登录状态、状态栏显示"已登出"
4. 按钮样式与 OBS 深色主题一致

### 账户信息刷新
1. 启动 OBS 并完成加载后，用户头像、昵称、等级、关注数等自动刷新为最新数据
2. 网络异常时 UI 保持显示旧缓存数据，不弹错误提示
3. 刷新完成后 `status_bar_` 短暂显示"账户信息已更新"
